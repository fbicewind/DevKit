### 30 MiB 基准

同机 ARM64 release 引擎测试，精确 31,457,280 字节，1,269,577 个值节点；不是浏览器原型测试。

| 操作                                | 耗时     |
| ----------------------------------- | -------- |
| 读取、严格校验、建立索引            | 66.2 ms  |
| 格式化导出 + 重新解析               | 133.4 ms |
| 压缩导出 + 重新解析                 | 113.3 ms |
| UTF-8 字节序递归排序导出 + 重新解析 | 155.8 ms |

本次完整基准约 1.12 s，节点索引约 43 MiB。此前单独运行测试二进制的 `/usr/bin/time -l` 测得进程最大 RSS 为 340,869,120 字节（约 325.1 MiB），该峰值包含基准保留的原始快照、输出重读快照和额外单字符串场景，**不代表 GUI 的峰值**。耗时仅反映本机一次实测，不构成所有硬件的时延保证。

基准同时验证：分页、数字字面量保留、三种输出重新解析后的节点数量一致、取消后没有残留目标文件、30 MiB 单字符串摘要长度受限并可导出。常规测试另覆盖 1,500,000 节点上限、64 MiB 文件上限、非法 UTF-8、长字符串写出期间取消和源文件保护。

### 构建兼容调整

当前主机为 macOS 27。Rust 1.90 的 LLVM 符号裁剪会生成部分无法加载的过程宏 dylib；release 与 build-override 明确采用 `strip = "none"` 后成功打包。相关上游记录：[rust-lang/rust#157750](https://github.com/rust-lang/rust/issues/157750)。

## 需要目标环境验收的项目

- 全新 macOS 用户目录拖拽安装与首次启动。
- Keychain 首次授权、拒绝授权后的恢复。
- 与其他应用实际争用全局快捷键时的系统行为。

这些检查需要真实系统条件；单元测试和浏览器测试不替代上述验收。

## 小窗口与 JSON 编辑上限修复

- 修复侧边栏内容在矮窗口中挤入状态栏的问题，导航独立滚动，品牌和底部操作区不再被压缩。
- 窄窗口的自动折叠改为实际状态控制；按钮和设置开关与显示一致，手动展开后不再被 CSS 强制折叠。
- JSON 编辑上限默认 10 MiB，设置页支持 1–64 MiB 整数，使用原子设置存储；旧配置无需手动迁移。
- Rust 的导入判定、编辑原文读取及格式化输出使用同一上限；超出上限返回稳定的 `LIMIT_EXCEEDED` 错误。
- CodeMirror 使用增量 UTF-8 字节计数，按修改片段计算，覆盖中文、Emoji、代理对拆分与合并。调低上限保留已有文本，仍允许缩减内容。
- 回归覆盖 900×420 与 520×420 下的按钮位置、连续收起/展开、设置保存与重载，以及超过原 2 MiB 限制的实际粘贴。

## 大 JSON 编辑器折叠修复

- 复现原因：CodeMirror 的语法树按视口和解析预算分段建立，大数组或跨越未解析区域的对象长期缺少折叠信息。
- 增加独立结构索引，按 UTF-16 位置记录多行对象与数组；跳过字符串内部的括号、引号转义，不读取或改写数值。
- 后台 Worker 建立索引并传回紧凑的范围数组；不支持 Worker 的环境分段扫描，保持界面响应。文档变化后立即取消旧任务并重建，销毁编辑器时释放任务。
- 折叠边栏在索引到达时主动刷新，支持外层数组、嵌套数组、根对象及远处对象的收起和展开；改善深色主题折叠占位按钮。
- 对齐 CodeMirror 的 state/view 依赖版本，避免同一编辑器加载多份核心类；保留撤销、搜索与原有折叠快捷键。
- 使用用户提供的本地 `m.json` 通过单元和界面回归：验证 `data`、`childClassList` 的实际点击收起/展开，以及所有非空容器的索引数量。原文件只读，样本不进入仓库。
- 验证包含约 5 MiB 合成数据、远处节点、快速替换文档、撤销及 Worker 不可用时的回退。

## JSON 编辑区独占显示

- 工具栏增加“隐藏节点树 / 显示节点树”按钮，隐藏后编辑区占满工作区宽度。
- 编辑器和节点树保持挂载，切换显示时保留输入与折叠状态；切换到其他工具再返回时保留显示方式。
- 超出编辑上限的只读大文件模式继续显示节点树。
- 1200 px 和 520 px 窗口回归覆盖隐藏、全宽布局、恢复、工具切换及编辑内容和折叠状态保留。
